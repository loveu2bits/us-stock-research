AI 资本开支周期：数据中心高增长还能持续几年？

→ FY27 净利 ±$450亿 · PE 20–30x
结论

能见度至少维持到 FY27Q2（指引 +95% 高于共识），但增速拐点何时出现是估值的第一变量——判定窗口在 2026-08 下旬财报。目前证据站多方。

对 EPS / 估值倍数的影响

影响最大。营收增速直接决定 FY27 净利润落点：资本开支持续（中性）→ ~$2,000 亿；继续上调（乐观）→ ~$2,400 亿；2027 见顶回落（悲观）→ ~$1,500 亿。

同时决定市场愿给的倍数：高增长叙事在 → 25-30x；周期见顶叙事起 → 20x 以下。两者叠加，悲观情景市值 -36% vs 乐观 +50%——这个问题就是全部赔率所在。

多方论点

  • FY27Q2 指引 $910 亿（+95%）显著高于市场共识，且管理层反复强调订单可见性
  • 「1 万亿美元订单管道」的超长期指引；四大云厂资本开支仍在扩张通道
  • 智能体 AI / 物理 AI 的 Token 消耗是聊天机器人的数倍，长尾需求才刚开始
  • 供应链承诺 $1,190 亿锁定产能——不是自己盲目扩产，是客户先付了承诺

空方论点

  • 增速已放缓：+126% → +114% → +66%，资本开支天然是周期性的，2027 年可能见顶
  • 前三大直接客户占营收 54%——云厂一旦集体转向，就是悬崖而非缓坡
  • FY2023 就是上一轮游戏/矿卡周期底部：这家公司历史上是有周期性的
  • 管理层开始大额分红回购，微妙信号：最疯狂的扩张期可能在见顶

毛利率 75% 守得住吗？

→ 每 1pct ≈ $27亿利润 · 失守则 EPS×PE 双杀
结论

目前守住了（74.9%），但方向是回落——中性预期 70-72%，这已计入估值；真正的危险线是 68%：跌破且归因「竞争定价」= 定价权叙事破坏。目前证据站多方，裂缝诚实记录。

对 EPS / 估值倍数的影响

毛利率每变动 1pct，在 ~$2,700 亿年化营收基数上 ≈ $27 亿利润，对 FY27 净利润（中性 $2,000 亿）影响约 ±1.3pct——单看温和。

但它是情景分水岭：回落至 70-72% 属中性（已定价）；若竞争把毛利率压向 60%（悲观假设），净利 $1,500 亿之外，「定价权」叙事同时破灭，倍数从 25x 压向 20x——EPS 与 PE 双杀，这就是悲观情景 -36% 的全部来源。

多方论点

  • CUDA 生态：750 万+ 开发者，客户的代码库、工程师团队、调优经验全长在上面，迁移成本极高
  • 系统级协同（NVLink / Spectrum-X / 机架级整体方案）：对手单点芯片追平，系统层面仍落后
  • 一年一代迭代节奏（Blackwell → Rubin），逼着追赶者永远差一代
  • 客户为「最低单位 Token 成本 + 最高单位功耗性能」付溢价——只要性价比领先，溢价就在

空方论点

  • 谷歌 TPU、亚马逊 Trainium 在特定推理负载上性价比已经成立，博通是最大受益者
  • HBM4/4e 等高价组件价值量占比提升 + 集成更多低利润率组件，毛利率存在向 60% 历史均值回归的风险
  • 中国市场因出口管制实质性丢失，间接养大了华为等对手
  • 大客户贡献 54% 营收，恰恰是这 54% 最有能力自研——客户越强，护城河越被从内部侵蚀

  • 大客户自研 ASIC 在特定推理负载性价比已成立

估值：$4.7 万亿市值隐含了什么预期？赔率如何？

→ 期望值 ≈ 现价 · 中性一年 +5%
结论

现价 ≈ 三情景期望值（$4.7 万亿 vs $5.2 万亿），没有安全边际，对应「持有」。上调为「买入」的两个触发条件：FY27Q2 上修订单管道（净利预期移向 $2,200-2,400 亿），或市值回落至 $4 万亿以下（前瞻 ~20x）。

对 EPS / 估值倍数的影响

这个问题本身就是估值问题。合理 PE 区间 20-30x：当前 31x 静态位于上沿、23-24x 前瞻位于中枢——倍数没有扩张空间，收益只能靠 EPS 兑现。

中性情景一年期回报约 +5%；赔率 ≈ 1.4:1（+50% / -36%，各 25% 概率）。不算诱人，所以持有而非买入。

多方论点

  • 前瞻 PE 仅 23-24x（FY27 中性净利 $2,000 亿），对 85% 增速的公司不算贵
  • 大规模分红回购 = 「成长 + 回报」转型，可能吸引价值型资金接盘，类比苹果启动资本回报后的估值扩张
  • Vera CPU 打开 $2,000 亿服务器 CPU TAM，CY2026 独立 Vera 收入指引 $200 亿——第二增长曲线未在现价定价

空方论点

  • 三情景期望值约 $5.2 万亿 ≈ 当前市值——现价已反映中性偏乐观预期，没有安全边际
  • 悲观情景（概率 25%）下行 -36%，乐观情景（概率 25%）上行 +50%，赔率 ≈ 1.4:1，不算诱人
  • $4.7 万亿市值本身就意味着：任何低于「极好」的兑现都是利空

公司概况

英伟达（NVIDIA）是全球人工智能（AI）计算领域的绝对领导者，已从图形处理器（GPU）供应商转型为数据中心级全栈AI基础设施公司。通过将硬件、系统、网络、软件和算法进行"极端协同设计"，构建了覆盖从芯片到AI工厂的完整解决方案。核心市场地位：GPU 在 AI 训练和推理市场占据约 80% 以上份额，并正通过 CPU、DPU 和网络产品大幅扩张 TAM。公司当前处于业绩高速兑现期，FY2026（截至2026年1月）营收达 2159.38 亿美元，最新一季度（FY27Q1）营收同比增长 85% 至 816.15 亿美元。

公司近况跟踪

  • 业绩持续超预期，指引强劲：FY27Q1 营收 816.15 亿美元，同比 +85.2%，环比 +20%，高于预期。毛利率 74.9%，符合指引。FY27Q2 营收指引中值 910 亿美元，同比约 +95%，显著高于市场共识。
  • 资本回报计划大幅升级：季度股息从每股 0.01 美元提升至 0.25 美元，额外批准 800 亿美元回购授权。管理层承诺 FY2027 将超过 50% 的自由现金流返还股东。
  • Vera CPU 成为新战略焦点：针对"智能体（Agentic AI）"时代设计，预计 CY2026 独立 Vera CPU 收入可达 200 亿美元，打开 2000 亿美元服务器 CPU TAM。已于 2026 年 6 月开始向客户出货。
  • 业务结构披露更新：FY27Q1 起重组为数据中心（细分为超大规模 Hyperscale + AI云/工业/企业 ACIE）与边缘计算两大板块。
  • 供应链持续扩张：FY27Q1 末制造、供应和产能承诺总额 1190 亿美元，其中 950 亿将在 FY2027 剩余时间内支付。

短期逻辑

  1. 资本回报驱动的估值重估：大幅提息+巨额回购，承诺 >50% FCF 用于股东回报，可能吸引价值导向和收益型投资者。历史上苹果启动大规模资本回报后经历类似估值扩张。
  2. Vera CPU 的叙事兑现与 TAM 扩张：直接挑战英特尔和 AMD 核心领地。关注实际订单和客户部署进展（OpenAI、Anthropic、Oracle 等）。
  3. FY27Q2 财报（8月下旬）为关键催化剂：关注营收/毛利率是否再超指引、"1万亿美元以上"长期订单管道是否更新、Rubin 平台进展。

长期逻辑

  1. 从"卖芯片"到"卖 AI 工厂"的商业模式升维：机架级整体方案大幅提高单笔交易规模，通过深度系统集成和软件绑定提高转换成本，从一次性硬件销售转向平台型收入。
  2. "智能体 AI"和"物理 AI"的长尾需求：智能体 AI 的 Token 生成量远超聊天机器人；物理 AI（机器人、自动驾驶）形成"仿真-训练-部署"持续算力消耗闭环。
  3. CUDA 生态护城河：750 万+ 开发者、海量优化库，极高迁移成本；Dynamo、NemoClaw 等新工具持续拓宽生态。

风险提示

  • 客户集中度与自研芯片风险：FY27Q1 前三大直接客户贡献营收 54%（21%/17%/16%）。谷歌 TPU、亚马逊 Trainium 等自研 ASIC 长期可能压制份额与利润率。
  • 毛利率压力：HBM4/4e 等高价组件价值量占比提升 + 系统集成更多低利润率组件，毛利率存在向 60% 历史均值回归的风险。
  • 地缘政治与出口管制：已被有效排除在中国数据中心计算市场之外，间接扶持华为等竞争对手。

业务模式及拆分

业务边际变化：从"GPU 供应商"向"全栈 AI 基础设施解决方案商"转型，数据中心收入占比 FY26 接近 90%；正将 Groq 的 LPU 技术整合进平台补齐超低延迟推理短板，并推出独立 Vera CPU 切入服务器 CPU 市场。

盈利模式：通过"极端协同设计"的系统级技术壁垒和 CUDA 软件生态锁定实现定价权；正从一次性硬件销售向与客户 Token 收入挂钩的持续服务收入模式演进。
