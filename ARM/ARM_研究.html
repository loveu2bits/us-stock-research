FY27Q1 财报：beat 了为什么还跌？2026-07-29 发布 · 营收/ EPS 双超指引，盘后却承压

→ FY27 版税增速预期 -数个pct · 估值叙事从「量价齐升」退守「以价补量」
结论

这是一次「现在时很好、将来时降级」的财报：beat 全在过去（营收、EPS、ACV 创新高），miss 全在未来（全年版税指引从约 20% 下调至高双位数、AGI CPU 需求翻倍却没上调收入目标）。手机疲软是真实的，但目前是「拖累增速」而非「破坏逻辑」——数据中心版税翻倍接过了增长引擎的位置。判定窗口在 FY27Q2：版税「低双位数」指引的兑现度。

对 EPS / 估值倍数的影响

直接影响 FY27 EPS 落点。版税占收入 55%，其全年增速预期从 ~20% 降至高双位数，叠加 Q2 版税指引仅「低双位数」，卖方 FY27 调整后 EPS 预测区间已落在 $2.06–2.28（一致预期 $2.15）——下修风险暂未出清。

对倍数的影响更微妙：手机版税「量减」靠 Armv9/CSS「价增」对冲，意味着版税故事从「量价齐升」退守「以价补量」——叙事的容错空间变小了，这正是盘后下跌而非上涨的定价逻辑。

多方论点

  • 营收 $12.89 亿（+22%）高于指引上限，Non-GAAP EPS $0.45（+29%）——核心兑现没有问题
  • 数据中心版税再次同比翻倍以上，Neoverse 核心累计出货超 15 亿颗、最近 5 亿颗仅用 9 个月——第二引擎已经点火
  • 授权收入 +23%、ACV $17.32 亿创新高（+13%）——授权是未来版税的先行指标，前瞻需求不差
  • 管理层历来指引保守：Q1 实际营收超指引上限，「高双位数」可能是压低后的预期管理

空方论点

  • FY26 移动应用处理器版税占总版税 约 43%——最大单一市场正在失速，内存涨价影响从低端蔓延至中高端
  • Q2 版税指引只有「低双位数」——减速不是一次性噪声，是连续两个季度的趋势
  • Q1 授权收入里含软银一单 $1.93 亿的技术授权及设计服务协议——beat 的含金量要打个折
  • AGI CPU 需求从 $10 亿+翻倍到 $20 亿+，管理层却没有上调短期收入目标——供给瓶颈比需求故事更硬

AGI CPU：需求 $20 亿 vs 产能 $10 亿——从 IP 授权到造芯，这一步跨得过去吗？

→ FY31 目标 $150亿芯片收入 vs 毛利率从 98% 稀释至 30–40% 起步
结论

需求端已被验证（客户订单超 $20 亿、较 3 月发布时翻倍，Meta 联合开发 + OpenAI/Cerebras/Cloudflare/SAP 签约），唯一的瓶颈是供给——晶圆、基板、测试、内存全线紧张，锁定产能仅支撑 $10 亿收入目标。这不是「能不能卖出去」的问题，是「能不能造出来」的问题；而一个从未造过芯片的公司，恰恰在最没有履历的环节被考验。

对 EPS / 估值倍数的影响

这是估值弹性的全部来源。管理层 FY31 目标：AGI CPU 收入 $150 亿 + IP 收入 $100 亿、EPS 超 $9——对照 FY26 收入 $49 亿，等于再造五个今天的 Arm。

但短期是反作用：第一代 AGI CPU 毛利率预计仅 高 30%–低 40%（vs 公司整体 98%），叠加研发费用率已升至 65%，芯片占比越高，报表利润率越难看。供给每多锁定一分 → FY28 收入上修一分；供给卡死 → 当前计入的乐观预期反噬。

多方论点

  • 需求已超 $20 亿（FY27+FY28），较 3 月发布时翻倍，且客户名单还在扩大（新增多家美国和中国客户）
  • 服务器 CPU 是 AI 时代被重估的赛道：AMD 把 2030 年 TAM 上调至 $2,200 亿，Arm 自己的 FY31 $150 亿目标仅占不到 7%
  • 架构优势有头部客户背书：英伟达 Vera 能效 2 倍于 x86、谷歌 Axion 性能 2 倍于前代、AWS Graviton 性价比 +40%
  • 管理层对超 $10 亿收入「信心在过去 90 天增强」——通常这是上修指引的前奏

空方论点

  • 首次造芯，制造/封装/测试/客户支持全无履历，却要和英伟达、AMD、英特尔抢台积电先进制程产能——供给是最大的未知数
  • 毛利率 30–40% 起步（目标几年后提到 50%）：芯片业务在结构性稀释 98% 毛利率的商业模式，估值体系可能要重构
  • 与英伟达、高通等大客户从合作变成竞合——客户转投 RISC-V 或加速自研的长期风险难以量化
  • 需求数字是「客户意向」不是「不可取消订单」，2026 年底才开始生产出货——从签约到收入确认还有很长的路

估值：目标价 $150–320 的巨大分歧里，赔率站在哪一边？

→ 期望值偏向下行 · 高盛 $150 与瑞银 $320 差了一倍
结论

这是一只「预期饱满 + 流通盘小」的股票：一致预期 FY27/FY28 EPS $2.15/$3.01 对应的远期 PE 仍处于极高水平，任何「低于极好」的兑现都会被惩罚。三情景期望值偏向下行，对应「持有偏谨慎」。上调触发条件：AGI CPU 供给实质突破（额外产能/明确交付时间表）或版税指引重新上调；下调触发条件：版税指引再降或芯片业务利润率路径证伪。

对 EPS / 估值倍数的影响

这个问题本身就是估值问题。分歧不在方向（没有券商否认长期叙事），在兑现概率：乐观方（瑞银 $320、摩根大通 $255）用远期 PE/PEG 为增长付费；谨慎方（高盛 $150、大摩 $212）认为现价已计入 AGI CPU 的乐观情形。

关键算术：管理层 FY31 EPS 目标超 $9，若给 40x 成熟期 PE 再折现回来，现价的隐含假设约等于「FY31 目标大概率兑现」——把五年后的完美当作基准情形，这就是赔率不佳的数学表达。

多方论点

  • FY28 一致预期 EPS $3.01，若 AGI CPU 供给打开、FY29 迈向 $4–5，极高远期 PE 会被增长快速消化
  • 服务器 CPU TAM $2,200 亿（AMD 口径），Arm 是 Agentic AI 时代几乎所有头部玩家的共同选择——结构性趋势的确定性高
  • 版税指引下修已砸出第一波情绪低点，若手机企稳或内存价格回落，存在预期差修复空间

空方论点

  • 卖方目标价 $150–320，最高与最低差超一倍——分歧大到这个程度，说明定价锚本身不稳
  • 芯片业务把毛利率从 98% 拉向 30–50% 区间，市场习惯的高利润率估值框架面临重构——EPS 涨、倍数跌，可能相互抵消
  • 流通股比例低，波动被放大；供给/版税任何一项不及预期，就是急杀而非阴跌
  • 悲观情形（高盛 $150）并非极端假设：只要求版税增速继续下台阶 + AGI CPU 供给平淡

公司概况

Arm Holdings plc 是全球半导体行业的计算平台领导者，其核心业务是设计并授权高性能、低功耗的 CPU、GPU、系统 IP 及计算子系统（CSS）。公司通过「IP授权+版税」的商业模式，为全球绝大多数智能手机、以及日益增长的云计算、汽车和物联网设备提供底层处理器架构。截至 2026 年 3 月，基于 Arm 架构的芯片累计出货量已超过 3500 亿颗，全球开发者社区超过 2200 万人。2026 年 3 月，公司宣布将业务拓展至生产硅芯片领域，推出了首款面向数据中心的 Arm AGI CPU，标志着其正从 IP 授权商向完整的计算平台解决方案提供商转型。

公司近况跟踪

  • FY27 Q1 业绩超预期，但全年版税指引下调：FY27 Q1（截至 2026-06-30）营收 $12.89 亿，同比 +22%，高于指引上限；Non-GAAP EPS $0.45，同比 +29%。但管理层将 FY27 全年版税收入增速指引从「约 20%」下调至「高双位数」，主因智能手机市场疲软超预期，盘后股价承压。
  • AGI CPU 需求强劲，但供给仍是核心瓶颈：客户需求已超 $20 亿（覆盖 FY27 和 FY28），较 3 月发布时翻倍。已锁定支撑 $10 亿收入目标的制造产能，但供应链（晶圆、基板、测试、内存）紧张仍是限制上调短期收入指引的关键因素。
  • 数据中心版税持续翻倍，成为核心增长引擎：FY27 Q1 数据中心版税收入再次同比翻倍以上，受超大规模云服务商（AWS、谷歌、微软）基于 Arm 架构的服务器 CPU 部署加速，以及英伟达 Grace 和 Vera CPU 持续放量驱动。Neoverse 核心累计出货超 15 亿颗，最近 5 亿颗仅用时 9 个月。
  • 智能手机版税疲软，但产品升级部分对冲：内存价格上涨的影响从低端蔓延至中高端市场，但 Armv9 架构和 CSS 渗透率提升带来更高的单芯片版税费率，部分抵消出货量下滑。
  • 授权业务保持强劲，ACV 创历史新高：授权及其他收入同比 +23%；年化合同价值（ACV）同比 +13% 至 $17.32 亿，创历史新高。

短期逻辑

  1. AGI CPU 供给进展是未来一个季度最核心的交易变量：市场对长期前景已充分定价，短期催化剂完全取决于供给端进展。管理层计划在 FY27 Q3 财报中提供更具体的更新；任何关于额外晶圆产能、锁定关键客户订单或明确交付时间表的信号，都可能触发正面重估。
  2. 智能手机版税增速放缓的预期差交易：全年版税指引下调至「高双位数」已引发负面反应。若实际表现优于保守预期（高端机型占比回升或内存价格企稳），存在预期差修复机会。
  3. 数据中心版税增长的持续性与估值支撑：若数据中心版税继续同比翻倍或接近翻倍，将有效对冲手机业务负面影响。英伟达 Vera CPU 进入量产、谷歌 Axion CPU 成为 TPU 系统主机等催化剂有望持续兑现。

长期逻辑

  1. Agentic AI 重塑数据中心架构，Arm CPU 成为核心枢纽：CPU 在任务编排、数据调度、内存管理和安全协调中的重要性急剧提升。Arm 预计到 2030 年服务器 CPU 市场规模超 $1,000 亿；英伟达、谷歌、AWS、微软等几乎所有主要 AI 基础设施提供商都在基于 Arm 架构构建下一代基础设施。
  2. 从 IP 到芯片，商业模式升级打开长期增长天花板：从单一 IP 授权商向「IP+芯片」双轮驱动转型。公司预计到 FY31，AGI CPU 业务收入达 $150 亿，IP 业务收入达 $100 亿，对应 EPS 超 $9。
  3. 计算平台的网络效应与生态护城河持续巩固：2200 万开发者、3500 亿颗芯片累计出货、云端到边缘端统一架构，构成强大的生态系统和网络效应。

风险提示

  • AGI CPU 业务的执行与竞争风险：首次进入生产硅芯片领域，面临制造、供应链、客户支持和市场竞争多重挑战；第一代产品毛利率预计仅为高 30% 至低 40% 区间，远低于公司整体 98% 的毛利率；并与部分 IP 客户（英伟达、高通）形成直接竞争。
  • 智能手机市场疲软与版税增长放缓风险：FY26 移动应用处理器版税占总版税收入约 43%；中高端机型因内存价格上涨和需求疲软承压，公司已下调全年版税指引。
  • 高估值与市场情绪波动风险：当前估值已计入大量未来增长预期；流通股比例较低，加剧股价波动性。

近期要闻

  • 2026-05-06：发布 FY26 Q4 及全年财报，营收创历史新高，正式宣布推出首款自研数据中心芯片 Arm AGI CPU。
  • 2026 年 5–7 月：多家投行上调目标价；AMD 在 7 月 Advancing AI 大会上将 2030 年服务器 CPU TAM 上调至 $2,200 亿。

  • 2026 年 8–10 月：公司预计在 FY27 Q3 财报（通常于 11 月发布）中提供 AGI CPU 业务更具体的收入和利润率更新及供应链进展说明。
  • 2026 年下半年：Arm AGI CPU 预计于 2026 年底开始生产出货，首批产品的交付和客户反馈是重要里程碑。
  • 2026 年 8–10 月：主要云服务商（Meta、微软、亚马逊等）财报和资本开支指引，将验证 AI 基础设施建设的持续性和规模。

业务模式及拆分

业务边际变化：正经历从纯 IP 授权商向「IP+芯片」双业务模式的历史性转变。2026 年 3 月宣布推出首款自研生产硅芯片 Arm AGI CPU，预计 2026 年底开始生产出货。

盈利模式：传统模式是「IP授权+版税」——授权收取前期许可费，客户芯片量产出货后按售价百分比或固定金额收取版税；毛利率约 98%，高粘性、长周期。芯片业务为直接销售硅芯片，初期毛利率预计高 30% 至低 40%，收入确认方式与传统业务显著不同。FY26 全年：版税收入占比 53%，授权及其他收入占比 47%。

版税业务：增长由「量」（芯片出货量）和「价」（单芯片版税费率）共同驱动。FY27 Q1 同比 +22%，主要驱动力来自云端 AI，数据中心版税再次同比翻倍；Armv9 和 CSS 渗透率提升带来更高单芯片版税费率；智能手机疲软形成拖累。

授权及其他业务：未来版税收入的先行指标。FY27 Q1 同比 +23%，本季度签署多份高价值协议，包括与软银的技术授权及设计服务协议（贡献 $1.93 亿）。ACV 同比 +13% 至 $17.32 亿。

核心竞争力

竞争要素 1：依托庞大软件生态和架构一致性构筑的平台网络效应——构成结构性护城河。超过 2200 万开发者、3500 亿颗芯片累计出货、云端到边缘端统一的指令集架构，形成高转换成本。FY26 年报显示 Arm 在智能手机应用处理器市场份额超 99%。动态演变：护城河变宽（巩固）——AI 向边缘设备扩展，公司通过 IP、CSS 和芯片多种形态降低客户采用壁垒。

竞争要素 2：在能效和定制化方面的技术领导地位——构成结构性护城河。英伟达宣布其基于 Arm 的 Vera CPU 能效比同类 x86 系统提升 2 倍；谷歌 Axion CPU 性能是前代 x86 方案的 2 倍；AWS Graviton 性价比比 x86 方案高出 40%。动态演变：护城河变宽（巩固）——架构授权（ALA）模式允许客户高度定制，比标准化产品的竞争对手更具优势。

现阶段核心驱动力总结：Alpha 在于平台生态和技术领导力，使其成为 AI 时代计算架构变革的核心受益者；Beta 与全球半导体周期、AI 基础设施投资力度及智能手机景气度高度相关。数据中心业务是最强结构性增长驱动力，智能手机周期性波动构成短期扰动。

产销链

  • 客户情况：客户集中度较高。FY26 前三大客户合计贡献 42% 总收入（16%/14%/12%），主要为全球领先的半导体公司和云服务商。AGI CPU 业务已宣布 Meta 为联合开发伙伴，并获得 OpenAI、Cerebras、Cloudflare、SAP 等客户，已新增多家美国和中国客户。
  • 供应商情况：传统 IP 业务为轻资产模式，无重大供应商依赖；AGI CPU 芯片业务开始深度依赖半导体制造供应链——晶圆（特别是台积电先进制程）、先进封装基板、测试产能和内存（HBM/DDR5）供应均非常紧张。
  • 成本传导能力：IP 业务几乎无上游成本，毛利率 98%；芯片业务利润直接受制于晶圆、封装等制造成本，第一代 AGI CPU 毛利率预计高 30% 至低 40%，计划通过部分外包环节内部化在未来几年提升至 50%。

行业及竞争分析

  • 服务器 CPU 市场：增长最快、空间最大的赛道。AMD 将 2030 年服务器 CPU TAM 预测上调至 $2,200 亿；据 IDC，基于 Arm 的加速服务器平台支出已超过 x86 平台。
  • 智能手机 CPU 市场：市占率超 99%，增长主要来自 Armv9 和 CSS 渗透带来的单芯片版税费率提升；当前面临终端需求疲软和内存涨价的短期逆风。
  • 嵌入式与物联网市场：Arm 低功耗 IP 是主导架构，AI 向边缘渗透带来新机会。
  • 竞争格局：x86（英特尔、AMD）是服务器和 PC 市场的传统霸主；RISC-V 开源架构在物联网和嵌入式市场构成潜在竞争；部分大客户（苹果、谷歌、亚马逊）拥有架构授权，具备深度定制甚至自研架构的能力。可比公司：新思科技（SNPS）、楷登电子（CDNS）、英伟达（NVDA）、英特尔（INTC）、高通（QCOM）。

市场焦点议题

  • AGI CPU 供给瓶颈与收入兑现节奏：已锁定产能仅支撑 FY27–FY28 共 $10 亿收入目标，而客户需求超 $20 亿；「信心增强」具体来自晶圆、基板还是测试产能？毛利率提升路径和时间表如何？
  • 智能手机版税放缓的持续性：疲软是内存涨价的成本推动型需求抑制还是结构性下滑？Armv9/CSS「价增」能否持续对冲「量减」？FY28 版税恢复 20% 以上增长的依据是什么？
  • 进入芯片业务对 IP 授权模式的潜在冲突：主要 IP 客户（高通、英伟达）反应如何？芯片业务是侵蚀 IP 业务的「搅局者」还是扩大生态的「双赢」？

市场分歧探讨

核心分歧点：AGI CPU 业务的长期价值是否已被当前股价充分甚至过度反映？

  • 乐观方：服务器 CPU TAM 2030 年达 $2,200 亿，Arm FY31 $150 亿目标仅占不到 7%；软件生态与开发者社区短期难以复制；需求已超 $20 亿且客户名单持续扩大。
  • 谨慎方：作为新进入者获取台积电先进制程产能面临巨头竞争；AGI CPU 还要与同样基于 Arm 架构的英伟达 Vera、AWS Graviton 竞争；芯片业务毛利率（初期 30–40%）结构性稀释整体利润率，高估值面临估值体系重构；进入芯片领域可能促使大客户加速布局 RISC-V。
  • 总结：长期叙事获充分肯定，短期在供给兑现、利润率变化和竞争动态上分歧显著。当前股价已计入较乐观预期，任何供给或利润率指引上的不及预期都可能导致较大幅度回调。
